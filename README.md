# PerfilWEB — Portafolio personal

Portafolio de **Iann Franco Hernandez Rojas** — Ingeniero de Sistemas.
Desarrollo y mantenimiento de software.

## Stack

- [Next.js 16](https://nextjs.org) (App Router, TypeScript)
- [Tailwind CSS 4](https://tailwindcss.com)
- [shadcn/ui](https://ui.shadcn.com) + [framer-motion](https://www.framer.com/motion/)
- Desplegado en [Vercel](https://vercel.com)

## Secciones

Inicio · Sobre mí · Habilidades · Proyectos · Experiencia · Contacto

## Desarrollo local

```bash
npm install
npm run dev
```

Abre http://localhost:3000 en tu navegador.

## Personalizar

Todo el contenido (sobre mí, habilidades, proyectos, experiencia y contacto) vive en
[`src/app/page.tsx`](src/app/page.tsx). Los enlaces están en las constantes `GITHUB_URL`
y `LINKEDIN_URL` al inicio del archivo.

## Despliegue

1. Entra a [vercel.com/new](https://vercel.com/new)
2. Importa el repositorio `iannfranco21/PerfilWEB`
3. Click en **Deploy** — no requiere variables de entorno
