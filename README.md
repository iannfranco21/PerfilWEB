# PerfilWEB — Portafolio personal

Portafolio de **Iann Franco Hernandez Rojas** — Ingeniero de Sistemas.

Desarrollo y mantenimiento de software: aplicaciones web, interfaces y soluciones a medida.

## Stack

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS 4** + shadcn/ui
- **Framer Motion** (animaciones)

## Desarrollo local

```bash
bun install
bun run dev
```

La aplicación corre en `http://localhost:3000`.

## Build de producción

```bash
bun run build
```

## Despliegue

El sitio se despliega en [Vercel](https://vercel.com) directamente desde este repositorio.
